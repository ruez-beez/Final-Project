# Explore the Solar System

## Responsive Website

## Project Description
Describe the final experience.

## Theme Interpretation
I took a literal interpretation of space. Making my website themed after the solar system. 

## Intended User or Player
My intended audience is younger individuals around ages 10-13 years with an interest in space history, astronomy, and learning. There is no previous knowledge of these topics required to use the website. There is an expectation that the user base has the ability to read and retain information.


## User or Player Goal
 The user should be able to navigate the homepage and other pages by interacting with the buttons and slide show to learn information about the solar system. 


## Main Features
The main content and where the interactions are located are on the homepage.  Here is where all the information on the topic of solar systems is. 

## JavaScript Features
One of the first interactions in the website is the planet slideshow. In this section there are buttons on the bottom where you can click to go to a previous or next slide.

The 2nd interaction is the FAQ section. Here you have to click on the question where it will open up the hidden answer section. 

At the bottom there is an automatic slide show that is under a 10 second timer.

## Responsive Design
When the screen becomes smaller than 600 pixels the layout becomes a single column layout. Text and images also react responsively, growing alongside the screen. 

## User Testing
My testing was primarily done by my peers and myself. From testing I learned that the user experience was severely lacking. Navigation through pages was non-existent due to broken links and there were missing javascript interactions. Other than that visually, there was little to adjust. 


## Revisions
My main revisions were to improve the user experience by fixing the links and creating the pages for the navigation. I also finished the javascript interactions,
